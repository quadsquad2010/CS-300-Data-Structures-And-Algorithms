# CS:300 Data Structures And Algorithms Portfolio


Project Overview:
  This repository contains artifacts from my work in CS-300 Data Structures and Algorithms. The projects focused on analyzing different data structures and developing a course planning application for academic advisors. The goal was to determine the most efficient way to store, search, and organize course information while also creating a working C++ program that could load course data, sort courses alphanumerically, and display prerequisite information.

What Problem Was Being Solved?:
  The primary problem was determining the most effective way to store and retrieve course information for an academic advising system. The system needed to efficiently load course data, organize it, display courses in     alphanumeric order, and allow advisors to quickly search for individual courses and their prerequisites. To solve this problem, several data structures were analyzed and compared before implementing the final solution.

How I Approached the Problem:
  I approached the project by first analyzing the strengths and weaknesses of vectors, hash tables, and binary search trees. Understanding data structures was important because the choice of structure directly impacts     program performance, memory usage, and efficiency when searching or sorting data. After comparing the options, I selected the structure that best met the project requirements and then implemented the design in C++.

Overcoming Roadblocks:
  One of the biggest challenges was reading course information from a file and organizing it correctly within the data structure. Another challenge was ensuring that courses were displayed in the correct alphanumeric     order while still allowing efficient searches. I overcame these roadblocks by breaking the program into smaller functions, testing each section individually, and refining the code until the output matched the project     requirements.

How This Project Expanded My Approach to Software Design:
  This project helped me better understand the importance of planning before coding. I learned that choosing the right data structure can significantly impact the performance and scalability of a system. Instead of       immediately beginning implementation, I now spend more time evaluating different design options and considering how they will affect the overall solution.

Writing Maintainable, Readable, and Adaptable Code:
  This project reinforced the importance of writing code that other developers can easily understand and maintain. I focused on using meaningful variable names, clear function organization, comments, and consistent       formatting. By separating tasks into smaller functions and documenting the code, the program became easier to debug, update, and expand in the future.
